# XMB Smart TV Launcher 📺🎮

Быстрый, ультра-легковесный и плавный лаунчер для **Android TV** (включая телевизоры со слабым железом и объемом ОЗУ ~1 ГБ), выполненный в премиальном стиле интерфейса **XMB (XrossMediaBar) / PlayStation**.

## 🚀 Особенности и преимущества

- **Ультра-низкое потребление ресурсов:**
  - 0% нагрузки на CPU/GPU в режиме покоя — статический шейдерный градиент и отсутствие постоянных прожорливых циклов перерисовки.
  - Потребление оперативной памяти $\sim 45-60$ МБ (вместо 250+ МБ у стандартных тяжелых лаунчеров).
  - Никаких утечек памяти и зависаний на бюджетных телевизорах (Haier, Yandex TV, Xiaomi TV и др.).
- **Настоящая навигация Leanback для пультов ДУ:**
  - Горизонтальная плавная лента с автоскроллом и фокусом по центру экрана.
  - Поддержка `D-Pad` (Вверх/Вниз/Влево/Вправо), клавиш `OK / Enter`, `Back` и `Menu`.
- **Пользовательская настройка скорости анимаций:**
  - Точная регулировка отклика шагами по 20ms: от мгновенного режима `0ms` (для максимальной скорости) до кинематографичных `240ms` (Android TV FastOutSlow).
- **Управление и сортировка приложений:**
  - **Зажатие OK:** открывает контекстное меню (Переместить, Скрыть, О приложении).
  - **Режим перемещения:** стрелками `◀` / `▶` на пульте можно легко расставить программы в нужном порядке или перенести в начало списка. Порядок сохраняется автоматически.
  - **Скрытие программ:** скрывает ненужные системные аппки из меню (с возможностью восстановить в любой момент через Настройки).
- **Нативное переключение входов ТВ:**
  - Встроенный сокетный клиент ADB (`127.0.0.1:5555`), вызывающий нативное меню входов Android TV (`KEYCODE_TV_INPUT` / HDMI 1, HDMI 2, AV, TV) без сторонних утилит.
- **Bluetooth и Пульты ДУ:**
  - Быстрый доступ к нативному экрану поиска и сопряжения Bluetooth устройств (`CONNECT_INPUT`).
- **Кастомные обои:**
  - Встроенные легковесные градиентные пресеты.
  - Проводник по любым папкам телевизора (`/sdcard`, флешки, загрузки) с поддержкой PNG, JPG и WEBP с авто-даунсэмплингом для защиты от OutOfMemory.
- **Индикатор Wi-Fi и часы** в верхней панели.

## 🛠️ Сборка проекта

### Требования
- Android SDK (API 26..34)
- Java / JDK 17
- Gradle (включен в репозиторий через `./gradlew`)

### Сборка через терминал
```bash
# Клонировать репозиторий
git clone https://github.com/USERNAME/xmb-tv-launcher.git
cd xmb-tv-launcher

# Собрать APK
./gradlew assembleRelease
# или отладочную версию:
./gradlew assembleDebug
```
Готовый файл APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

### Установка на телевизор через ADB:
```bash
adb connect <IP_ВАШЕГО_ТЕЛЕВИЗОРА>:5555
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 🎮 Управление с пульта

| Кнопка пульта | Действие |
|---|---|
| **Влево / Вправо** | Листание приложений в ленте / выбор настроек |
| **Вверх / Вниз** | Переключение между категориями / верхней панелью |
| **OK (Короткое нажатие)** | Запуск выбранного приложения |
| **OK (Зажатие на 0.5с)** | Контекстное меню (Переместить, Скрыть, Инфо) |
| **MENU** | Быстрое открытие меню смены обоев |
| **BACK** | Закрытие окон и возврат к ленте |
